# Artifact Workspace Export Guide

Exports are governed operations, not direct browser downloads. The renderer first flushes autosave and requires a clean, non-conflicting revision. It requests backend preflight for an explicit artifact, current revision, format, actor, and workspace. The backend checks RBAC, policy, classification, format support, license state, and size, then returns a short-lived one-time ticket with a safe suggested basename and byte limit. Tauri opens the native dialog, writes atomically, and commits the expected SHA-256 and size; cancellation and failure are reported to the backend.

The exact format matrix is: Document JSON/Markdown/HTML; Form schema JSON, memory-only submission JSON, and memory-only submission CSV; Code Source/TXT; Flow JSON/SVG/PNG; Spreadsheet CSV/XLSX; Canvas JSON/SVG/PNG; Slides PPTX/JSON. Spreadsheet CSV targets one explicitly selected sheet using deterministic UTF-8 RFC 4180, while XLSX includes all sheets and formula-like strings remain text. Canvas and slide rendering use only governed local assets. Code exports exact stored LF/CRLF source bytes under a safe filename and never executes content.

Every kind opens the same export dialog. It displays format, suggested filename, saved revision, data class, policy state, estimated size, and a security warning before the native destination picker opens. Form submission export reads only the current in-memory form session for the exact artifact/revision key; it does not create browser persistence or weaken submission policy.

Basenames are Unicode-normalized and reject separators, controls, trailing dots/spaces, dot names, and Windows device names. Fixed formats force their extension. Export code must reject NaN/Infinity, unsafe active content, unsupported media, oversize output, ticket expiry, hash mismatch, replay, wrong actor/workspace/revision, and destination changes after authorization.

Operators enable exports with `artifact_workspace.export.enabled` only after editor and native boundary tests are green. Audit must show pending followed by completed, cancelled, or failed. No renderer payload, log, support bundle, or export record may contain the destination absolute path or reusable ticket. If corruption, injection, replay, or hash mismatch is observed, disable export and the global workspace gate, preserve files and audit, run integrity, and follow the recovery runbook.
