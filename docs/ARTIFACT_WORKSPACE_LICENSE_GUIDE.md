# Artifact Workspace License Guide

Spreadsheet and canvas have two trusted adapter paths: an optional commercial adapter and a bundled local fallback. A trusted backend doctor verifies signed entitlement evidence before selecting a commercial package for the exact product/version, production license mode, permitted target, offline permission, validity window, activation mechanism, approval, and activation smoke. Missing entitlement selects `bundled_fallback`; it does not disable the governed editor. The renderer receives only the redacted runtime capability snapshot and never receives a key, evidence path, entitlement payload, reusable digest, secret reference, or vendor response.

Renderer feature flags can only disable. They cannot manufacture capability or select an adapter. Backend mutation enforcement is mandatory: if neither a verified commercial adapter nor the bundled fallback is available, create/edit/paste/save/AI apply returns `ARTIFACT_LICENSE_UNAVAILABLE` and creates no revision. Stable doctor reasons include feature disabled, evidence missing/invalid/expired, forbidden mode, version mismatch, target mismatch, offline unverified, unsupported activation, package missing, and `ARTIFACT_BUNDLED_FALLBACK_ACTIVE` for the accepted local path.

The bundled spreadsheet editor supports bounded cell/range editing, sheet operations, copy/paste, CSV/XLSX export, autosave/revisions, conflict handling, and a virtual row window; formula evaluation remains disabled. The bundled canvas supports local shapes, text/notes, line/arrow/free draw, selection/resize, undo/redo, zoom/pan, governed local assets, and JSON/SVG/PNG export; remote embeds remain denied. Commercial chunks are never imported when their entitlement is unavailable. A Vite or renderer boolean may further disable either surface but may never enable backend authority.

Run the compatibility/release adapter gate before installing or shipping commercial packages. Exact package pins and lockfile hashes must match approved evidence. Logs, metrics, diagnostics, support bundles, RPC errors, and release reports may include only non-secret package/version/reason/adapter status. Missing or stale commercial evidence must select the bundled fallback and is never a reason to bypass the doctor. Entitlement ambiguity, activation failure, missing fallback, or secret leakage is a no-ship condition.
